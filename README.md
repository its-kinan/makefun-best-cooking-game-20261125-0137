The Copper Ladle — a tiny top-down cooking game: run a one-chef kitchen through three dinner shifts. Grab ingredients from the pantry, chop them on the boards, cook patties and pots on the stoves (watch the burn timer), plate dishes on the counter and serve them at the window before the ticket's patience runs out. Five recipes, growing order pressure, combos and tips, three hearts, three days.

## Run it

```sh
node serve.ts
```

Then open http://127.0.0.1:8080/ — WASD/arrows to move, E or click to grab, chop, cook, plate and serve, P to pause, M to mute. No build step, no network: everything the game loads is a file under game/.
